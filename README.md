# Circles Bot (кружки)

Telegram-бот с кружками на **Python + aiogram 3**, **PostgreSQL** и **Redis**.

## Возможности

- 🌐 Два языка: RU / EN (выбор при старте и в меню)
- ▶️ «Следующий кружок» — случайный кружок из общей базы, отправляется как video note (кружок)
- 📤 Загрузка видео до 20 МБ / 60 сек прямо из чата на сервер; обычное видео автоматически конвертируется в кружок (ffmpeg)
- 👤 Профиль: загружено/оценки/просмотрено/баланс/подписка
- ⭐️ Профиль автора: цена доступа, фото-шапка, описание, вывод заработанного
- 👀 Смотреть профили: покупка доступа к кружкам автора, лайки/дизлайки
- 💰 Экономика: 5 монет на старте, 1 монета за просмотр
- 💳 Покупка монет: CryptoBot (@send), Telegram Stars, скрин перевода с подтверждением админом; цены в рублях конвертируются в $ по актуальному курсу ЦБ
- 🆓 Бесплатно: реферальная ссылка и подписка на спонсоров
- 🎫 Подписки: А+ (7 дней, 100/день), A++ (7 дней, безлимит + пересылка/скачивание), PREMIUM (навсегда)
- 🔒 Обязательная подписка на каналы-спонсоры
- 🤖 Зеркала: любой пользователь создаёт зеркало бота своим токеном, общая БД
- 🧹 Проверка зеркал: токены через Bot API (getMe → setMyDescription → getWebhookInfo) и Telethon-клинер (`/start` с реальных аккаунтов, жалобы, чистка мёртвых сессий)
- 🛠 Админ-панель `/admin`: статистика, рассылка (с инлайн/линк кнопками), начисление баланса, подтверждение оплат, заявки на вывод, изменение цен и настроек, спонсоры, зеркала, тест-оплата

## Запуск

Все настройки задаются в `config.py` в корне проекта (`.env` не используется):
BOT_TOKEN, CRYPTOBOT_TOKEN, ADMIN_IDS, реквизиты оплат, зеркала, Telethon.

```bash
docker compose up -d --build
```

После правки `config.py`: `docker compose up -d --build bot`.

Для Telethon-клинера положите `*.session` файлы в `storage/sessions`
(без них клинер просто ничего не делает; выключается `TELETHON_CLEANER_ENABLED = False`).

Или без Docker (нужны PostgreSQL, Redis и ffmpeg):

```bash
pip install -r requirements.txt
python main.py
```

## Настройки через админку

`/admin` → «Цены и настройки»: пакеты монет, цены подписок, цена просмотра,
стартовый баланс, награда за реферала. Формат: `ключ значение_в_JSON`.
